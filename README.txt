Repository de mise en application du cours "Initiez-vous au Machine Learning" sur Open Classrooms.
https://openclassrooms.com/fr/courses/8063076-initiez-vous-au-machine-learning

Pour recréer l'environnemnt :
```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```
Pour exécuter le code :
```
cd ~/initiez-vous-au-machine-learning
source .venv/bin/activate
python linear-regression-1.py
python linear-regression-2.py
etc
deactivate
```
